# 🛒 BlinkIT Grocery Sales Analysis | Power BI Dashboard

## 📌 Project Overview

This project presents an interactive **Power BI dashboard** built using BlinkIT grocery sales data. The dashboard provides valuable business insights into sales performance, customer ratings, outlet performance, and product distribution to support data-driven decision-making.

The project demonstrates skills in **Power BI, Data Cleaning, Data Modeling, DAX, KPI Development, and Data Visualization**.

---

## 🎯 Business Objective

The objective of this project is to analyze BlinkIT grocery sales data and answer important business questions such as:

- Which outlet generates the highest sales?
- Which product categories perform the best?
- How do outlet size and location impact sales?
- What is the average customer rating?
- Which outlet types contribute the highest revenue?
